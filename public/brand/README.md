# Official logo

`router-logo.png` is the official original logo supplied for Multi-Queue Router Simulator, included unchanged at its original 1672 × 941 dimensions.

The sidebar, mobile header and navigation, and dashboard welcome section display the image with its original aspect ratio and `object-fit: contain`. The full artwork remains visible without cropping or stretching. No generated or generic logo replaces it.

`router-favicon.png` is a 64 × 64 browser icon extracted from the router-symbol portion of the official image. The full original logo file remains unchanged.
